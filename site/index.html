How this was measured

Built like a desktop app, because it is one

Many AI agent apps are web pages in an Electron window. The Harlo app is Rust and Qt from top to bottom, so it starts at once and sits quiet.

A Rust core
Agent streams, transcripts, diffs, git and search run in compiled Rust, on threads of their own. Long sessions don't slow the window down.
A Qt Quick interface
Drawn by your GPU with Qt 6, the toolkit behind KDE Plasma. No HTML, no JavaScript framework, no bundled Chromium.
At home on Linux
Native windows on Wayland and X11, your system's notifications, input methods and file dialogs, a drop-down window, and packages for your distribution.
31 themes, dark and light
Harlo’s own, Catppuccin, Gruvbox, Nord, Solarized, Rose Pine and more, with your fonts and text size.

Read what the agent did before you keep it

  • Diffs side by side or inline, with syntax highlighting.
  • Undo a turn: the files go back as they were before it, in every repository it touched.
  • Commit, push and open a pull request, then follow its checks. When they fail, hand the failure to the agent.

The Harlo agent passed all 25 tasks with the fewest input tokens

Harlo’s own coding agent, on your ChatGPT plan, an OpenAI key or your own models, with the commands it runs kept to the project. Against two other open-source coding agents on the same tasks and model: 31% fewer than pi, under a third of opencode’s.

A wiki of your code, so your agents look things up first

  • Written from the code: Create wiki has your agent write its architecture and workflows, each fact tied to its lines (with OpenWiki, included).
  • Read in sections: agents search it and read only what they need; you read it in the Wiki panel.
  • Kept current: Update rewrites only the pages whose code changed.

Plans for bigger work, one step at a time

  • A plan you can edit: the agent works through the steps; reorder, change or skip any of them.
  • Run with helpers: a session per step, steps that don't depend on each other at once, each reviewed by another agent.
  • Choices as cards with a Choose button, diagrams as pictures, and mockups of a UI change.
