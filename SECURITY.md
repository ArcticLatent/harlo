# Security

harlo pairs phones with your computer, encrypts what passes between them,
and runs a relay that forwards those messages. If you find a way to read or
change what it protects, to pair without permission, or to misuse the relay,
please tell us privately first.

**Email hello@harlo.run** with what you found, how to reproduce it, and what
it lets someone do. Please don't open a public issue or pull request for it.

We'll reply within a few days, keep you updated while we fix it, and credit
you in the release notes if you'd like.

Fixes go into the latest release; please update to it (harlo updates itself:
Settings → General → Check for updates).
